# ML / AI Research

This feed tracks machine learning models, training infrastructure, fine-tuning workflows, and research-oriented AI tooling.

## Repositories

- [PufferLib](https://github.com/PufferAI/PufferLib) — Puffing up reinforcement learning.
- [verl](https://github.com/verl-project/verl) — Flexible and efficient RL post-training framework.
- [TradingAgents](https://github.com/TauricResearch/TradingAgents) — Multi-agent LLM financial trading framework.
- [Jackrong-llm-finetuning-guide](https://github.com/R6410418/Jackrong-llm-finetuning-guide) — LLM fine-tuning guide.
- [LLM-fine-tuner](https://github.com/Yog-Sotho/LLM-fine-tuner) — No-code LLM fine-tuning.
- [autoresearch](https://github.com/karpathy/autoresearch) — AI agents running research on single-GPU nanochat training automatically.
- [ANE](https://github.com/maderix/ANE) — Training neural networks on Apple Neural Engine via private APIs.
- [heretic](https://github.com/p-e-w/heretic) — Training-free language model modification.
- [deepseek-harness](https://github.com/Habib0x0/deepseek-harness) — Personal harness and experiments around model evaluation.
- [supertrend-ai-predictor](https://github.com/Habib0x0/supertrend-ai-predictor) — AI predictor experiment.
