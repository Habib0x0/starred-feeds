# Developer Tools, Interfaces & Terminal

This group focuses on desktop tooling, terminal interfaces, UI frameworks, browser access, and developer productivity tools.

## Repositories

- [the-via/app](https://github.com/the-via/app) — App project.
- [slint](https://github.com/slint-ui/slint) — Open-source declarative GUI toolkit.
- [rtk](https://github.com/rtk-ai/rtk) — CLI proxy to reduce LLM token usage.
- [design.md](https://github.com/google-labs-code/design.md) — Design spec format for coding agents.
- [carbonyl](https://github.com/fathyb/carbonyl) — Chromium running inside the terminal.
- [netwatch](https://github.com/matthart1983/netwatch) — Network diagnostics in your terminal.
- [Gource](https://github.com/acaudwell/Gource) — Software version control visualization.
- [artcraft](https://github.com/storytold/artcraft) — Crafting engine for artists and designers.
- [FiTui](https://github.com/ayanchavand/FiTui) — Terminal-based expense tracker in Rust.
- [ratatui](https://github.com/ratatui/ratatui) — TUI library for Rust.
- [mcp-ui](https://github.com/MCP-UI-Org/mcp-ui) — UI over MCP.
- [webtmux](https://github.com/chrismccord/webtmux) — Web-based terminal with tmux-specific features.
